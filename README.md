# OpenPhysics-Lab

OpenPhysics-Lab is an open-source collection of physics simulations, numerical experiments, and visualizations.

The project focuses on building small, understandable computational experiments that connect physics and mathematics with numerical computation.

## Goals

OpenPhysics-Lab aims to make computational physics:

* Reproducible
* Understandable
* Well documented
* Scientifically validated
* Easy to contribute to

## Topics

The project may eventually include simulations covering areas such as:

* Classical mechanics
* Oscillations
* Waves
* Gravitation
* Orbital mechanics
* Electromagnetism
* Thermodynamics
* Numerical methods
* Computational physics

## Simulations

The simulation collection is currently being developed.

Each simulation will aim to document:

* The physical model
* Governing equations
* Assumptions
* Parameters and initial conditions
* Numerical methods
* Results
* Validation
* Known limitations

## Scientific validation

A simulation should not be considered correct simply because its output looks reasonable.

Where possible, numerical results will be checked against analytical solutions, known physical behavior, conservation laws, convergence tests, or other appropriate validation methods.
